# Structural Bookshelf V2 — semantic ablation proof

This is a deliberately content-free fixture, superseding the invalid
V1 Score/artwork-based claim. It asks what *the Bookshelf itself* can
communicate before content and iconographic identities are added.

The test removes every source image, Score, publisher logo, displayed title,
nameplate, authored sentence and content-derived page count. Only structural
differentiation remains: publisher-position circle, occupied vs empty slots,
collection drill-down, stable order, parent return and three neutral,
identical reading leaves per work. Empty slots have no interaction.

**Actual limitation:** A person cannot intrinsically tell which anonymous
occupied tile is Essays or First Readings, nor which identical work is
which, without contextual memory, position or external labels. The
browser proof does not claim perceptual semantic legibility.

## Grounded structure

- Two admitted collections: Essays and First Readings.
- Three source-authored works in Essays.
- One admitted First Readings work.
- Four distinct collection-bound encounters, with shared authored identity.
- All four encounter readers have three visually identical blank test
  leaves regardless of the actual source artwork/image count.
- Source work SHA-256, collection ID, parent and route persist as
  machine-readable metadata, **not** cover artwork.
- No First Hearing published or inferred.
