## Verified semantic learnings

The source work `teatro-an-unfinished-composition` retains one original
authored source fingerprint while admitting two **distinct collection-bound
encounters** under `essays` and `first-readings`. A collection has a stable
identity and a parent route, not merely a surface title. The cover is the
source-attested work artwork; empty slots have no route or identity.

The visual projection has two top-level collections, three original Essays
works, one admitted First Readings work, and six encounters with original
images (five distinct source artworks). All visible prose, headings, labels,
and page numbering are omitted from the projection. Text contained in genuine
original artwork is retained, not regenerated or redacted.
